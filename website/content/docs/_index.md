chi (χ) is an open-source autoresearch harness: it points a fleet of LLM coding
agents at any problem that exposes a programmatic evaluator — a build, a
correctness check, and a score — and iterates unattended.

These pages cover the practical surface. For the full design rationale, see the
specs in the repository's `docs/` directory.
